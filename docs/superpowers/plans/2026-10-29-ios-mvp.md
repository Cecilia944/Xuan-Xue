# 紫微斗数 iOS MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个 iOS 17+ 原生 MVP，可离线录入出生资料、准确排盘、浏览卡片/罗盘命盘、保存三张档案并展示 Free/Pro 权益边界。

**Architecture:** 在仓库新增 Xcode workspace 与独立 `ZiweiCore` Swift Package。核心算法、时间校正和领域模型不依赖 UI；SwiftUI App 通过 repository/use-case 接口访问 SwiftData 与权益状态。迁移期使用当前 TypeScript 回归样例作为跨语言金标准。

**Tech Stack:** Swift 6、SwiftUI、Swift Testing、SwiftData、StoreKit 2、CloudKit（MVP 仅保留接口）、CryptoKit、Xcode 18+

**Spec:** `docs/superpowers/specs/2026-10-29-ios-free-pro-design.md`

## Global Constraints

- Deployment target 为 iOS 17.0；应用代码使用 Swift 6 严格并发检查。
- 基础排盘必须完全离线且永久免费。
- 不确定出生时间不得默认伪装成精确子时结果。
- 夏令时/真太阳时跨日或跨时辰不得静默采用。
- 精确出生信息不得写入日志、分析事件或分享图片。
- 每张持久化命盘必须包含算法版本、内容版本与流派配置快照。

## Review Focus

- 闰日、无效日期和农历闰月：拒绝无效输入，合法日期稳定换算（Task 2）。
- 23:00 晚子时与真太阳时跨日：根据规则生成候选并要求确认（Task 3）。
- 1986–1991 中国夏令时：只提示可调整，不自动扣除（Task 3）。
- 空命宫借对宫、四化和亮度：Swift 结果必须与金标准一致（Task 4）。
- 删除档案及分享：删除持久化数据；分享不泄露精确时间地点（Task 8、9）。
